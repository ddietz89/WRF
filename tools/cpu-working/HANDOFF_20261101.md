## 3. How to run (tools preserved in `campaign/spot100-20261016/session-tools-20261101/`)

- `guarded_arm.sh <pkg> <run-id>` (set `CANDIDATE_SHA`): stage → prepare → clear → launch → wait → reconcile →
  contention audit. `arm_with_reader.sh <pkg> <run-id> <tag>` adds the original exact reader + collector
  (`READER_POLLS=200` for 9h). Edit the hard-coded `SP=` scratch path inside both before reuse.
- New package = `cp -a` an existing package, delete generated files (`stage-only-result.txt prepare-*.txt
  launch-*.txt cache-clear-*.json candidate-closures.json local-*.txt negative-gate-checks.json RESULT*.json
  reader-closure.json science-receipt.json candidate-metadata control-metadata reader-launch.txt
  CONTENTION_AUDIT.json`), sed the old run id to a new one in `* adapter/*`, re-pin `source-pins.json`.
- Staging is create-only: any attempt that reached staging needs a new run id.
- Executable swaps: `clean_swap.py` (clean-tree layout `WRF/main/`) or `flat_swap.py` (flat build dir). 9h
  packages import `check as child` instead of `check as child_build` — edit by hand.
- Feature patches (all gated on lease fields, absent = original behaviour): `colperm_patch.py`,
  `smt_patch.py`, `tables_patch.py`, `devstat_patch.py` (ignore `st_dev` in stat admission after the /pool
  remount; needed in every package created from pre-reboot packages).
- Object-swap recipe for one module on the 352f image: compile the clean tree's preprocessed `.f90` with the
  exact clean compile line (`clean-full-source-7bde78fc-tpifix-r4/compile-pass1.log`), verify parent recompile
  reproduces the 352f member's `.text/.rodata/.data` and `.mod` is unchanged, `ar r` in place (member order
  unchanged), relink with 352f's own command (`radar-memo-r1/link352f.json`). Relinking the unchanged archive
  reproduces `352f86ce` exactly.
- Thompson TPI member IS reproducible: canonical `module_mp_thompson.F` + `-DWRF_EXPERIMENTAL_TPI_NUMA` +
  `shared_table_iso.mod` (from `WRF/tools/cpu-memory/thompson-table-sharing/shared_table_iso.f90`) →
  `.text 637a6edd7699` identical (`thompson-r1/REPRODUCTION.md`).
