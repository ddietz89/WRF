# Provider qualification provenance

The current working default is `fused-pack`: provider source `b938317c`, full shim `172306f3`. Its native, complete-caller and actual world-512 short-application evidence is under [fusion/](fusion/) and `optional_build_variants.fused-pack` in [qualification.json](qualification.json). It removes the intermediate packed buffer by writing active rows directly into shuffled byte planes. The package selector has not been rebuilt merely for this default change; the selected artifact comes from its separately pinned native build.

The original provider/shim and its one-hour, three-hour and prior build epochs remain in [historical-qualification-4cb.json](historical-qualification-4cb.json). `--provider original` selects that source. The parent world-16/64 sources and installed dependencies remain unchanged.

The retained `--provider simd-pack` source `e29a6a59` combines the exact SIMD shuffle replacement (`37c9d541`) with four audited packing edits: job metadata, per-job initialization, packing after worker affinity, and removal of the serial packing loop. Its literal source is retained under `parallel-pack/`. The packing and shuffle API responses, rejected literals, independent-review dispositions and full inverse proofs remain under `investigation/wrf-cpu/source-discovery/provider-parallel-pack-next-r1/` and `shuffle4-simd-next-r1/`. Exact exports were approved; no credentials or scientific arrays were sent.

Separate native `375aa7e3` and actual world-512 application receipts are bound in [qualification.json](qualification.json). The optional application passed both original complete products, 185 steps and all runtime/lifetime guards; its retained-control timing was slower. Original default and optional build branches reproduced their qualified library bytes in one closed unit; [variant-build/result.json](variant-build/result.json) and its closure preserve those receipts. Build reproduction adds no model coverage.
