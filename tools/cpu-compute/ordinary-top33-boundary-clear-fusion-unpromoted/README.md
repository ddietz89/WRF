# TOP33 boundary-clear fusion: closed, unpromoted

The intended source/codegen mechanism and bounded correctness passed. The complete caller was slower in both node orders, so this variant is closed without canonical, owner, archive/image, application, default, or selected-record integration. Selected parent `90f5` remains unchanged; this candidate was not in its ABBA campaign.

Each arm ran 256 complete 36-call families (9,216 calls), CPU24/4GiB/zero swap with a 180-second hard cap. All four retained identical 380,123,136-byte raw reference SHA `ddf8ed9f81e8b0776de64958d29402280656512334ca12662c66870c605602b2`, read-only/guard/five-state checks, checked cache clearing before each arm, and positive manager/empty absent cgroup closures. Call wall/process CPU sums cover only callee intervals. Whole-arm elapsed times were 60.234, 64.148, 59.866, 66.692 seconds and include work outside those clocks.

R1 failed to start GNU13.3 on hpc00 because required GLIBC versions were absent; no candidate compile or numerical result. R2 stopped before numerical suites at the required extra absent optional argument in `rk_tendency`. A fresh exact-object proof preserved all 41 old arguments, 58 branch destinations, 101 relocation roles, and constants; root approved that named ABI-only route prospectively for R3. Both failed jobs remain failed. R3 then passed five roles, whole-RK30/family36/direct3/new-permission8 raw/state controls and normal closure. Legacy direct3 is a regression suite, not proof of all requested entry modes; the new8 suite rearms actual requested state. There is no standalone theta or full application qualification.

Actual codegen removed the caller's separate TOP memset traversal and placed the guarded literal +0 store after the original two boundary flux stores in the existing I loop. The same TOP bytes are written. The 228 eliminated memset invocations per family come from source/fixture geometry, not a runtime counter. Neither codegen nor these two observations establish a hardware cause, universal regression, statistical significance, or forecast effect.

The timed-only caller change was the repeat literal32→256; original untimed checks, numerical code, clocks, and state oracles remained unchanged. The 30-second draft was preserved; root explicitly authorized the separate 180-second package because outside-clock checks also scale with repeats.

Rollback: none. No TOP33 source/default integration occurred. Retain the immutable failures, fresh ABI proof, native pass, actual codegen, and four arm receipts; do not rescreen this variant without a new measured mechanism. Evidence paths and SHA256 bindings are in `DECISION.json` and the two scoped records. This directory is a private publication proposal only.
