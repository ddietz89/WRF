## Profiles and references

The full-grid 1500×1140 development profile attributes substantial startup time to initial output (96.42 s). Selected-rank steady samples identify positive-definite scalar advection (10.55%), ordinary scalar advection (5.66%), scalar update (3.92%), AFWA driver (3.26%) and RH calculation (1.88%). These are sampled self costs, not additive inclusive call-tree fractions or a complete critical-path attribution.

A subsequent 60-second, two-rank debug profile on the independently initialized 450×342 common case collected about 5,000 samples with zero loss. Its self costs include positive-definite advection 7.05%, vertical-velocity advancement 5.31%, ordinary advection 5.13%, Thompson microphysics 4.56%, AFWA driver 3.48% and RH calculation 1.38%. Domain and forecast phase differ; these percentages do not establish whole-stage gains.

The common case preserves 2.5 km spacing, 33 vertical levels, CONUS physics, adaptive timesteps and hourly output. It has its own physically generated initial/boundary inputs, not slices of a larger domain. The original six-hour run completed in 1,412.40 s; distributed execution took 1,634.31 s under shared development load. These are not authoritative scaling measurements.

The original protected scientific checker remains unchanged. An additive validator verifies layout, timestamps, inventory, restart files and first divergence; 18 mutation tests pass. Job-local per-variable read-cache management changes resource use, not the comparison predicate. Observed timestep equality uses the precision printed by WRF (two decimals); internal timestep-bit equality is unobserved.

## Correctness findings

`phys/module_diag_afwa.F` passes `terrain_dx` and `terrain_dy` to `LLT_MountainWave` without declarations, assignments or supplied arguments. A scan of 743 source files finds no other binding. The helper directly uses those values, and its result feeds precisely the four failed diagnostics. Controlled unchanged-helper tests demonstrate large changes in this four-field family when only explicit synthetic terrain coefficients change. This supports the defect diagnosis; it is not a capture proving the exact live values that caused every observed mismatch.

A separate cloud-ceiling typo uses undefined `ceil_min` instead of the declared 125 m `min_ceil`. A separate correction passes five boundary tests under bounds checks and O2. It is not included in any performance build.

The owner-approved separate terrain correction defines physical grid-aligned slopes using `MAPFAC_MX/MY` and `rdx/rdy`, centered interior differences, and one-sided physical mass-grid boundaries. The original has no defined stencil to preserve. Flat/linear, variable-metric, quadratic boundary and decomposition-window tests pass O0 bounds checks and strict O2. The complete AFWA module builds under the retained strict flags. Three actual independent DeepSeek reviews and their limitations are retained.

The corrected executable (`5729ec328e3df27909a0660534ddd780cba24bd58f3d1be900067e0af9cfab06`) passes stock-versus-zlib-ng all-field/metadata/layout exact comparisons at hours 0, 1 and 2; all 365 observed adaptive steps match. Legacy-versus-corrected hour 0 passes, hours 1 and 2 fail only the four LLT diagnostics; those strict failures remain preserved. This establishes a separate reference for further experiments, not full forecast qualification or a performance gain. Scope is nonperiodic CONUS Lambert with at least two physical cells per axis. Allocation-edge derivatives, polar/periodic cases and the one-layer LLT hazard remain unqualified. The separate ceiling typo is excluded.

The source correction is committed separately from performance candidates. Legacy source commit `06d4240ae989cc3e50af412bb472df3d9048783c` and all original binaries/receipts stay immutable. Roll back the correction by reverting its isolated commit. Longer, restart, holdout and full-duration qualification remain pending.

## Corrected combined qualification and restart finding

The owner-approved terrain baseline versus the combined advection row cache and RH output guard passes all seven hourly outputs for a six-hour common-domain run. Combined stock versus job-local zlib-ng also passes all seven outputs. Every scientific field, metadata item and storage-layout check is exact, and all 1,085 observed timestep records match. No field exceptions or tolerances apply. The independent October weather holdout also passes all seven hourly products (275 fields each), complete metadata/layout and all 1,085 observed timestep records. This adds held-out weather evidence without a cross-host timing claim.

The combined source/zlib-ng build also passes strict resumed-parent versus resumed-candidate comparison for the hour-2 history and restart: every field, metadata item and layout is exact, and all 180 observed timesteps match. This qualifies candidate equality along this resumed path; it does not resolve the separate baseline continuous-versus-resumed failure.

Development wall times were 1,573.280 s for the corrected parent on hpc02, 1,403.214 s for combined source on hpc04, and 1,382.705 s for combined source/zlib-ng on hpc03. Hosts, shared load and the last placement differ: these are descriptive observations, not an established stage or pipeline speedup. Performance source changes remain unpromoted while bounded matched timing is prepared.

The separate corrected continuous-versus-resumed test fails: hour-2 history has 96 variable-value failures and restart has 175. Differences include prognostic and soil state, despite all 180 logged post-checkpoint timesteps matching. Maximum diagnostic U difference is 0.182 m/s and perturbation temperature difference is 0.0688 K; this does not establish a rounding-only cause. The restored-state startup capture matches the checkpoint at all sampled physical locations. A subsequent continuous/resumed first-physics capture passes the full continuous hour-1 checkpoint integrity check and matches all 1,291,824 sampled rows bitwise through seven stages, including the first cumulus call. The known pre-adaptation clock intervals differ but the next exact timestep is 20 seconds in both runs. Five subsequent cuts also pass the full hour-1 checkpoint integrity check and match 942,480 selected rows through RK stages 1–3, microphysics and the end of the first complete 20-second solve. This is selected-column evidence. A complete physical-domain capture of 56 defined fields at the end of that first solve subsequently found 18 differing `W_2` cells near the northern boundary, on rank 12; all other 55 fields and remaining physical `W_2` cells are bitwise equal. An example differs by one raw float bit (`bcc7ef69` versus `bcc7ef6a` at i=65, k=2, j=339). The full continuous hour-1 checkpoint integrity check still passes. Halos and other state are outside this capture, and neither the cause nor its relationship to later widespread differences is established. No first-divergence repair is established. Original strict failures and the separately reviewed segment-provenance failure remain preserved. No restart qualification or numerical tolerance is claimed.

An original-source full-grid repeat also fails precisely the four LLT diagnostics in both evolved histories and both restart snapshots; initial output passes, every other field/metadata/layout check passes, and all 11 logged steps match. This evidence remains attached to the legacy reference.
